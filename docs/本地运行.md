# 校园助力车项目本地运行

## 环境

- JDK 17、Maven、Node.js、MySQL 8.0.16 或更新版本、Redis 兼容服务。
- 默认 MySQL 数据库名为 `campus_bike`，后端端口 8080，前端开发地址 http://127.0.0.1:5173。
- Windows 本机课程环境可使用仅监听 127.0.0.1:6379 的 Memurai Developer。该版本仅供开发测试，最长连续运行 10 天，之后需要重启；其他成员也可以使用 Redis。

## 初始化数据库

新建专用空数据库后，按 [数据库脚本说明](../sql/campus/README.md) 导入若依基础脚本和校园业务脚本，随后依次导入账号、站点、车辆、租借、报修、费用、报表和设置菜单。若依基础脚本包含删表语句，不要对已有业务库重复执行。

校园普通用户请分配 `campus_user` 角色。若依自带的 `common` 示例角色包含后台权限，不能当作普通用车用户。示例账户和默认口令仅供本地初始化，实际使用前请修改。

全新导入若依示例数据时，应用管理员账号为 `admin`，示例用户为 `ry`，初始应用密码均为 `admin123`；它们与 MySQL 的 root 账号和密码无关。请登录后立即修改密码，并在用户管理中为普通用户分配 `campus_user` 角色、移除 `common` 角色。本机新建的项目库已经完成 `ry` 的角色调整。

## 后端

在项目根目录执行：

```powershell
mvn -B -DskipTests package
node scripts/start-local.cjs
```

启动脚本优先使用环境变量 `DB_USERNAME`、`DB_PASSWORD`、`APP_TOKEN_SECRET` 和可选的 `DB_URL`。本机如已通过项目配置生成 Windows 用户加密文件，脚本可自动读取；该文件不在项目或 Git 仓库中，并且只能由创建它的 Windows 用户读取。其他组员需自行设置本机连接信息和足够随机的令牌密钥，禁止把密码提交到 Git。

备份需本机有 `mysqldump`，可通过 `MYSQL_DUMP_PATH` 指定其路径；`CAMPUS_BACKUP_DIR` 指定备份目录。需要完整备份时，可使用 MySQL 的登录路径并在环境变量 `CAMPUS_BACKUP_LOGIN_PATH` 中指定名称；对应账号应有读取表、视图、触发器、事件和存储过程的权限。备份文件包含数据库内容，请妥善保管。

## 前端

在 `ruoyi-ui` 目录执行：

```powershell
npm ci
npm run dev
```

浏览器访问 http://127.0.0.1:5173。开发代理会将接口请求转发至本机 8080 端口。生产环境需要将前端静态资源和接口代理部署到同一受控站点；请勿直接暴露开发服务器。

## 本地版本管理

每个业务模块单独提交。菜单脚本导入后应重新登录，以刷新角色和菜单权限；数据库结构变更使用新增迁移脚本，不重复执行初始建表脚本。
