# 校园助力车系统测试记录

测试日期：2026-11-04。环境：Windows、JDK 17、MySQL 8.0.42、Redis 兼容服务 Memurai Developer、Chrome。业务写入测试使用独立 MySQL 实例、独立 Redis 数据库和临时账号；本机项目库仅用于登录、菜单、报表和备份验证。

## 构建与页面

- 后端 Maven `package -DskipTests` 打包成功；该命令跳过 Maven 测试，下面的检查为独立执行的接口、数据库和浏览器验证。
- 前端 Vite 生产构建成功；登录页、普通用户首页、可借车辆、我的租借、我的账单、管理员报表和设置页面进行了浏览器检查。移动端首页在 390 像素宽度下无横向溢出；检查期间没有捕获到页面 JavaScript 异常。

## 核心业务与权限

| 项目 | 实际结果 |
|---|---|
| 登录与权限 | 管理员和普通用户登录成功；普通用户访问管理员报表、车辆管理和备份接口被拒绝。 |
| 借车并发 | 两个用户同时借同一辆车，恰好一人成功；重复借车被拒绝。 |
| 数据隔离 | 其他用户不能归还不属于自己的订单。 |
| 报修与还车 | 借出车辆报修后仍保持借出；还车时有未完成工单则转为维修，工单完成后恢复空闲。 |
| 计费与账单 | 还车生成唯一账单；重复还车被拒绝。新收费规则生效后，历史订单保留原规则和金额。 |
| 欠费与缴费 | 未结清账单时不能再借车；模拟缴费成功，相同请求可重试，不同请求重复支付被拒绝。 |
| 异常订单 | 管理员可标记异常并结算；产生处理记录，普通用户不能自行结束异常订单。 |
| 黑名单 | 加入黑名单后，已有会话被拒绝且重新登录失败；解除后可恢复。 |
| 公告 | 下线公告对普通用户不可见，管理员仍可查看。 |
| 报表 | 车辆总数与站点汇总、账单应收与已缴和欠费进行了对账；日期筛选口径见报表页面说明。 |
| 备份 | 本机数据库备份生成非空文件；在独立 MySQL 实例中恢复并核对 11 张业务表、2 个站点和 2 辆车，恢复副本随后清理。 |

## 范围说明

支付为模拟流程，没有接入真实支付渠道。没有进行大规模压力测试、长时间稳定性测试或真实车辆硬件联调；上线或多人高并发使用前需要补充。
